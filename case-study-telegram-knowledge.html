01
📤

You send text, a photo, PDF, Excel, Word, JSON, or XML file on Telegram.

Smart Router:
System identifies the file mime-type and routes it for automatic content extraction.

Can it read Excel files and PDFs?
▼
Yes. The system uses specific nodes to extract structured data from Excel and XML, and converts PDFs and Word Docs into clean text before embedding them into the vector database.
What if a customer is angry or complaining?
▼
The system detects complaint-like sentiment and flags those chats for priority manual follow-up, so no unhappy customer is missed.
Does the customer need to type special commands?
▼
No. Customers type naturally and the bot understands regular conversation with no menus or keywords required.
Can this work for other types of businesses?
▼
Yes. The flow adapts to any catalog-based business using WhatsApp for sales: electronics, fashion, auto parts, and more.
